## API REFERENCE

### Creating Nodes
```python
node_var = nodeType.create(x, y)
```

### Connecting Nodes
```python
target.connect("input_name", source.id, "output_name")
```

### Setting Values
```python
node.set("input_name", value)
```

## POSITIONING RULES

- **Event nodes**: Start at x=2
- **Horizontal spacing**: x + 8 (standard), x + 10 (wide nodes)
- **Vertical spacing**: y + 6 (for branches)
- **Connected nodes**: Keep same Y coordinate
- **Branches**: Increase Y for each branch

## CRITICAL RULES

### Input/Output Parameter Names
**IMPORTANT: Some nodes have SPECIFIC parameter names that differ from others:**

**Event nodes with uppercase N:**
- everyFrame and everyTick use `"N"` (uppercase), not `"n"`
- Example: `event.set("N", 1)` NOT `event.set("n", 1)`

**Loop delay parameter:**
- for_ node uses `"x"` for delay parameter (mapped to __delay__)

**Output naming:**
- Most nodes use `"answer"` for output
- getObjectPos uses `"x"` and `"y"` outputs
- for_ uses `"index"` output
- setObjectVar has NO value output (only path)

### Working with Objects
**ALWAYS get object ID by name first before using object nodes**

**NEVER use createObject for movement/manipulation - objects already exist on scene**

```python
# CORRECT - Get existing object ID and move it
get_id = getObjectIDByName.create(10, 10)
get_id.set("name", "player")
move = moveObject.create(18, 10)
move.connect("id", get_id.id, "id")

# WRONG - Don't create object for movement
create = createObject.create(10, 10)  # BAD - only for spawning NEW objects
create.set("name", "player")
move = moveObject.create(18, 10)
move.connect("id", create.id, "id")

# WRONG - Don't use hardcoded IDs
move = moveObject.create(10, 10)
move.set("id", 0)  # BAD
```

**Use createObject ONLY when:**
- Spawning new objects (bullets, coins, enemies, etc.)
- Creating multiple instances in loops
- Dynamically generating objects

**Use getObjectIDByName when:**
- Moving existing objects
- Manipulating player/enemies already on scene
- Working with any pre-existing scene objects

**ALL object manipulation nodes require getting ID first:**
- moveObject, moveObjectWithBraking, setObjectPos, getObjectPos
- setObjectRotation, jump, removeObject
- setObjectVar, getObjectVar
- setObjectParameter, getObjectParameter
- getResultingVector
- runAnimation, stopAnimation, mirrorAnimation
- ifCollision (for id parameter)

### DO
- Use `everyFrame` + `displayText` for continuous text display
- Use `writeText` for console output
- Use `displayText` for on-screen text
- Store node.id in variable ONLY if used multiple times
- Increase Y coordinate for each parallel branch
- Keep connected nodes at same Y coordinate
- ALWAYS use `getObjectIDByName` before object manipulation
- Use uppercase "N" for everyFrame and everyTick
- Check node outputs before connecting (setObjectVar has no value output)
- Check the names of the inputs and outputs, they must match.

### DON'T
- Add comments to code
- Use `createObject` when working with existing objects (movement, rotation, etc.)
- Use hardcoded object IDs - always get ID by name first
- Connect wrong output types to inputs
- Use `displayText` without `everyFrame` for persistent text
- Store unnecessary variables
- Use lowercase "n" for everyFrame/everyTick (must be uppercase "N")
- Try to connect non-existent outputs (check node definition first)
