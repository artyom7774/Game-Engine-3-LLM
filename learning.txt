# START

A NODE IS A UNIT FOR WRITING CODE IN A PROGRAM
THEY COME IN THE FOLLOWING TYPES: events, loops, text, numbers, logic, objects, animation, another, set, music, experimental
YOU SHOULD DO INDENTS FROM NODES ON 2 POINTS (DO NOT FORGET ABOUT THE WIDTH AND HEIGHT OF THE OBJECT)
PROGRAM LOGIC STARTS WITH NODE IN GROUP EVENTS
YOU MUST FOLLOW THE STRUCTURE AS ACCURATELY AS POSSIBLE WHEN WRITING NODES

THE PHRASE "RETURNS THE PATH" MEANS THAT ALL NODES IN WHICH THE PATH IS OBTAINED FROM THIS NODE ARE LAUNCHED FOR EXECUTION
"standard" IS VALUE WHAT SET VALUE OF NODE, BUT "value" IN A LINK TO GET VALUE FROM LAST NODE AND HAVE PATH FOR CONNECTOR AND NODE ID

# NODE TYPES

## EVENTS
THIS TYPE OF NODES RETURNS PATH UNDER A GIVEN CONDITION
HAVEN'T GOT VALUE FOR PATH

# NODE STRUCTURE

"id": {
    "type":        !COPY THIS PARAMETER FROM ALL NODES LIST! $TYPE OF NODE$ (events, loops, text, etc.)
    "name":        !COPY THIS PARAMETER FROM ALL NODES LIST! $CODE NAME OF NODE$ (onStartGame, writeText, etc.)
    "x":           $POSITION OF NODE BY X$
    "y":           $POSITION OF NODE BY Y$
    "width":       !COPY THIS PARAMETER FROM ALL NODES LIST! $WIDTH OF NODE$ (10, 12, 6, etc.)
    "height":      !COPY THIS PARAMETER FROM ALL NODES LIST! $HEIGHT OF NODE$ (5, 6, 3, etc.)
    "id":          $RANDOM NO ZERO UNIQUE NUMBER$ (EXAMPLE: 12341542134, 6523451245, 842359975)
    "sorting":     !COPY THIS PARAMETER FROM ALL NODES LIST! <SORTING ALL INPUTS AND OUTPUTS PARAMS> (EXAMPLE: {"inputs": ["path", "text", "start", "end"], "outputs": ["path", "text"]})
    "inputs":      !USING TEMPLATE FROM ALL NODES LIST AND YOU CAN REPLACE "STANDARD VALUE" AND "VALUE"! <INPUTS NODE PARAMETERS, ANY PARAMETER CALLED CONNECTOR> (EXAMPLE: {"path": {"code": "path" <DOUBLES KEY OF CONNECTOR>, "name": "__path__" <NAME FOR USING IN TRANSLATING>, "standard": null <STANDARD VALUE OF PARAMETER>, "type": "path" <TYPE OF CONNECTOR>, "value": {"id": 81376843 <ID FROM NODE WHERE GET THIS PARAMETER>, "name": "path" <CODE NAME OF NODE PARAMETER FROM GET VALUE>}})
    "outputs":     !USING TEMPLATE FROM ALL NODES LIST AND YOU CAN REPLACE "STANDARD VALUE" AND "VALUE"! <OUTPUTS NODE PARAMETERS> (EXAMPLE: {"path": {"code": "path" <DOUBLES KEY OF CONNECTOR>, "name": "__path__" <NAME FOR USING IN TRANSLATING>, "type": "path" <TYPE OF CONNECTOR>})
    "display":     !COPY THIS PARAMETER FROM ALL NODES LIST! <DISPLAY NAMES OF NODE NAME AND CONNECTORS> (EXAMPLE: {"name": "node.name.writeText" <CODE FOR NODE NAME>, "text": {"__none__": "node.text.none" <ALWAYES REQUERED>, "__path__": "node.text.path", "__text__": "node.text.text"})
}
