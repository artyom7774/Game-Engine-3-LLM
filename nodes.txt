# COMPACT NODES REFERENCE

## EVENTS (trigger program execution)
Size: 6x3 | Inputs: none | Outputs: path

- onStartGame - triggers when game starts
- onLoadScene - triggers when scene loads
- mouseLeftClick - left mouse button click
- mouseRightClick - right mouse button click
- keyboardClick(key:"") - keyboard key press (single)
- keyboardPress(key:"") - keyboard key hold
- onButtonPress - UI button press, outputs: path, id
- everyFrame(N:1) - every N frames
- everyTick(N:1) - every N game ticks

## LOOPS (cycles)
Outputs: iterator, after (path after loop completion)

- for_(8x4): path, n:1, delay:0 → iterator, index, after
  Repeats n times with delay

- forObjectsGroup(8x4): path, group:"object" → iterator, id, after
  Iterate through objects in group

- forListElements(10x5): path, list:[] → iterator, index, element, after
  Iterate through list elements

- forDictElements(10x5): path, dict:{} → iterator, key, element, after
  Iterate through dictionary key-value pairs

## MATH (mathematical operations)
Size: 8x4 | Inputs: path, a:0, b:0 | Outputs: path, answer

- plus - addition (a + b)
- minus - subtraction (a - b)
- multiply - multiplication (a × b)
- divide - division (a ÷ b), b:1
- modulo - remainder (a % b)
- pow(8x4): path, number:0, degree:0 → path, answer - power
- sqrt(6x3): path, number:0 → path, answer - square root
- absolute(6x3): path, number:0 → path, answer - absolute value

## TRIGONOMETRY
Size: 6x3 | Inputs: path, x:0 | Outputs: path, answer

- sin - sine (x in radians)
- cos - cosine (x in radians)
- tan - tangent (x in radians)
- ctg - cotangent (x in radians)
- radians(6x3): path, degrees:0 → path, radians - degrees to radians
- degrees(6x3): path, radians:0 → path, degrees - radians to degrees

## TEXT (text operations)

- writeText(6x3): path, text:"" → path
  Output to console

- displayText(10x5): path, x:0, y:0, text:"" → path
  Display on scene (for 1 frame, use with everyFrame!)

- connectText(8x4): path, text1:"", text2:"" → path, text
  Concatenate text

- sliceText(10x5): path, text:"", start:0, end:-1 → path, text
  Extract substring

## OBJECTS (object operations)

- createObject(10x5): path, name:"", x:0, y:0 → path, id
  Create object

- removeObject(6x3): path, id:-1 → path
  Remove object

- setObjectPos(10x5): path, id:-1, x:0, y:0 → path
  Set position

- getObjectPos(8x4): path, id:-1 → path, x, y
  Get position

- moveObject(10x5): path, id:-1, angle:0, power:1 → path
  Move at angle with power

- moveObjectWithBraking(12x6): path, id:-1, angle:0, power:1, slidingStep:1000000000 → path
  Move with braking

- jump(8x4): path, id:-1, power:10 → path
  Jump

- setObjectVar(10x5): path, id:-1, name:"", value:"" → path
  Set object variable

- getObjectVar(8x4): path, id:-1, name:"" → path, answer
  Get object variable

- getObjectIDByName(6x3): path, name:"" → path, id
  Get ID by name

- getAllObjectInGroup(6x3): path, group:"" → path, objects (list of IDs)
  All objects in group

- getResultingVector(8x4): path, id:-1 → path, x, y
  Object movement vector

- setObjectParameter(10x5): path, id:-1, name:choose, value:"" → path
  Set parameter (hitbox, mass, layer, gravity, etc.)

- getObjectParameter(8x4): path, id:-1, name:choose → path, value
  Get parameter

## LOGIC (conditions)

- if_(10x5): path, a:null, b:null, operation:0 → path_true, path_false
  Comparison (operation: 0==, 1!=, 2<=, 3>=, 4<, 5>)

- ifCollision(10x5): path, id:-1, group:"object", append:false → path_true, path_false, id_in_group
  Check collision

- ifKeyInDict(8x4): path, dict:{}, key:"" → path_true, path_false
  Check key in dictionary

- ifElementInList(8x4): path, list:[], element:"" → path_true, path_false
  Check element in list

## ANIMATION

- runAnimation(8x4): path, id:-1, animation:"" → path
  Start animation

- stopAnimation(6x3): path, id:-1 → path
  Stop animation

- mirrorAnimation(10x5): path, id:-1, horizontal:false, vertical:false → path
  Mirror animation

## VARIABLES

- setVar(10x5): path, name:"", global:false, value:"" → path
  Set variable (global=true for entire project)

- getVar(8x4): path, name:"", global:false → path, answer
  Get variable

## DATA STRUCTURES (lists and dictionaries)

### Lists
- addListElement(8x4): path, list:[], element:"" → path, list
- insertListElement(10x5): path, list:[], index:1, element:"" → path, list
- getByIndex(8x4): path, list:[], index:0 → path, element
- deleteByIndex(8x4): path, list:[], index:0 → path, list
- getIndexOfElement(8x4): path, list:[], element:"" → path, index
- sliceList(10x5): path, list:[], start:0, end:-1 → path, list

### Dictionaries
- addDictElement(10x5): path, dict:{}, key:"", element:"" → path, dict
- getByKey(8x4): path, dict:{}, key:"" → path, element
- removeByKey(8x4): path, dict:{}, key:"" → path, dict
- getKeyOfElement(8x4): path, dict:{}, element:"" → path, key

## UTILITY (helper functions)

- random_(8x4): path, a:1, b:2 → path, answer
  Random number from a to b

- len_(6x3): path, element:"" → path, answer
  Length of text/list/dictionary

- wait(6x3): path, time:100 → path
  Pause for time frames

- getMousePos(8x4): path → path, x, y
  Cursor position

- getTimePassed(6x3): path → path, time_passed
  Time since game start

- decodeHolder(6x3): path, text:"" → path, answer
  Parse text to data

- exit_(6x3): path → no outputs
  Stop script

- break_(6x3): path → no outputs
  Exit loop

## SCENE (scene management)

- goToScene(6x3): path, scene:"" → path
  Go to scene

- getSceneName(6x3): path → path, answer
  Current scene name

## FUNCTIONS (custom functions)

- functionEvent(6x3): name:"", params:[] → path, params
  Define function (params invisible)

- callFunction(8x4): path, name:"", params:[] → path
  Call function

## MUSIC (sound)

- playMusic(8x4): path, name:"", volume:1 → path
  Play music

- stopMusic(6x3): path → path
  Stop music

- playSound(8x4): path, name:"", volume:1 → path
  Play sound

## PYTHON (custom code)

- python(10x5): path, text:"def run(program, args, kwargs):\n\tpass", list:[], dict:{} → path, answer
  Execute Python code (list and dict invisible)
